# Project Instructions

- Keep `AGENTS.md` at the repo root as the canonical workflow instruction file.
- For non-trivial work, use `.agent/plan.md` (tracked) with a short ordered task list; keep it minimal and current.
- Record durable, cross-session context in `.agent/context.md` (tracked).
- Use `.agent/scratchpad.md` for temporary session notes only (local/untracked).
- Legacy orchestration artifacts are deprecated for active workflow: `.sop/`, `.ralph/`, `PROMPT.md`, and `ralph.yml`.
- For Python work, follow generally accepted Python conventions, patterns, and norms unless the project docs specify otherwise, and if they do, flag this.
- Read the contents of `docs/` to stay familiar with the project scope, contracts, and plans before starting implementation work.
- Keep documentation aligned with behavior: when adding or changing functionality, update the relevant docs in `docs/` (and README if user-facing).
